# Einführung/Beschreibung
Komfortfunktionen in Dokumenten, die der Standard nicht bietet 
LeBit-Korrespondenz-Layout erleichtert und beschleunigt die Arbeit mit Dokumenten 
Der Korrespondenzdokumentensatz enthält 13 Standardberichte, die zusätzliche Funktionen haben, die kein lokalisiertes Standardsystem darstellen.
